# Палиндром

## Объяснение решения

Для проверки числа на палиндром переворачиваем число.

Сначала сохраняем исходное число в переменную `orig_num`. 
Затем последовательно берем последнюю цифру числа с помощью операции `% 10` и добавляю её к перевёрнутому числу(rev_num).

После получения последней цифры удаляем её из исходного числа с помощью целочисленного деления `// 10`.

Например, для `12321`:

- `12321 % 10 = 1`
- `1232 % 10 = 2`
- `123 % 10 = 3`
- `12 % 10 = 2`
- `1 % 10 = 1`

В результате получаем перевёрнутое число `12321`.

Затем сравниваю исходное число с перевёрнутым. Если они равны, число палиндром.

## Оценка сложности

**По времени O(log n)**

log тк на каждой итерации делим на 10 (тк в О-нотации основание логарифма не важно, записываем без него).

**По памяти: O(1)**

Используется постоянное количество переменных, поэтому дополнительная память не зависит от размера числа. 
Все вычисления выполняются непосредственно с исходным числом, без создания дополнительных массивов или строк.
(т.е. если число становится больше, количество переменных orig_num, rev_num, digit, num не изменяется)
