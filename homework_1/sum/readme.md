# Сумма

## Объяснение решения

Сначала вычисляем сумму всех элементов массива.

Если сумма чётная, то она уже является максимальной суммой, которая
делится на 2.

Если сумма нечётная, необходимо убрать одно нечётное число.
Чтобы получить максимально возможную сумму, убираем самое маленькое
нечётное число.

## Оценка сложности

**По времени O(n)**

Сначала вычисляется сумма элементов, а затем массив один раз
просматривается для поиска минимального нечётного числа.
Поэтому количество операций линейно зависит от количества элементов
массива.

**По памяти: O(1)**

Используется постоянное количество дополнительных переменных,
которое не зависит от размера массива.


## Визуализация работы алгоритма

Рассмотрим массив:

[5, 7, 13, 2, 14]

Сумма всех элементов:

5 + 7 + 13 + 2 + 14 = 41

Сумма нечётная, поэтому ищем минимальное нечётное число:

| Число | Нечётное? | Минимальное нечётное |
|---:|:---:|---:|
| 5 | Да | 5 |
| 7 | Да | 5 |
| 13 | Да | 5 |
| 2 | Нет | 5 |
| 14 | Нет | 5 |

Убираем `5`:

41 - 5 = 36

36 делится на 2, поэтому ответ:

**36**
