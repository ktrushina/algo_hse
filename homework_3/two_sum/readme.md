# Two sum

## Объяснение решения
идем по массиву: для каждого числа ищем, не встречалось ли число `k - п` раньше. Для быстрого поиска используем хеш-таблицу (dict)


## Алгоритм
• Используем хеш-таблицу для быстрого поиска нужного числа

• На каждом шаге проверяем, есть ли `k - п` в таблице

• Если есть - возвращаем индексы

• Если нет - сохраняем текущее число и его индекс



## Почему используем `dict`

```python
needed in seen
```
тут поиск ключа в среднем занимает O(1) благодаря хеш-таблице (нам не нужно каждый раз искать нужное число по всему массиву)


## Оценка сложности

**По времени O(n)**
Массив просматривается один раз

**По памяти: O(n)**
В худшем случае в хеш-таблице будут сохранены почти все элементы массива

## Визуализация

             
             ТЕКУЩЕЕ ЧИСЛО
                    │
                    ↓
              num = arr[i]
                    │
                    ↓
             needed = k - num
                    │
                    ↓
          ┌─────────────────────┐
          │ needed есть в seen? │
          └─────────────────────┘
              │             │
             НЕТ            ДА
              │             │
              ↓             ↓
       запоминаем       нашли пару!
       num → index      seen[needed], i
              │
              ↓
          следующий
          элемент

## Пошаговое выполнение

arr = [1, 3, 4, 10]
k = 7

 
| Итерация | `i` | `num` | `needed = k - num` | Состояние `seen` | Результат |
|---:|---:|---:|---:|---|---|
| 1 | `0` | `1` | `6` | `{1: 0}` | `6` нет в `seen` |
| 2 | `1` | `3` | `4` | `{1: 0, 3: 1}` | `4` нет в `seen` |
| 3 | `2` | `4` | `3` | `{1: 0, 3: 1}` | `3` найден → `(1, 2)` |
