# Anagrams

## Объяснение решения
Слова считаются анаграммами, если у них *одинаковый набор букв*. Используем *хеш-таблицу*, где ключ - это *отсортированное слово*

## Алгоритм
• Сортируем буквы в слове

• Используем отсортированное слово как ключ

• Кладем в одну группу, если ключи совпадают


## Оценка сложности

**По времени O(n*klogk)**
n - количество слов
k - макс длина слова (сортировка каждого слова)
(O(klogk) - из-за сортировки)

**По памяти: O(nk)**
тк храним группы и ключи
