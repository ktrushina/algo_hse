# Anagrams

## Объяснение решения
Слова считаются анаграммами, если у них *одинаковый набор букв*. Используем *хеш-таблицу*, где ключ - это *отсортированное слово*

## Алгоритм
• Сортируем буквы в слове

• Используем отсортированное слово как ключ

• Кладем в одну группу, если ключи совпадают


## Оценка сложности

**По времени O(n*klogk)**
n - количество слов
k - макс длина слова (сортировка каждого слова)
(O(klogk) - из-за сортировки)

**По памяти: O(nk)**
тк храним группы и ключи

## Визуализация

 ```            
слово
  ↓
сортируем буквы
  ↓
получаем ключ
  ↓
ключ есть в dict?
  ↓
 ┌───────────┐
 НЕТ         ДА
 ↓            ↓
создаём      добавляем
группу       слово
 ``` 

## Пошаговое выполнение
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

| Итерация | `word` | `key = ''.join(sorted(word))` | Состояние `groups` |
|---:|---|---|---|
| 1 | `"eat"` | `"aet"` | `{"aet": ["eat"]}` |
| 2 | `"tea"` | `"aet"` | `{"aet": ["eat", "tea"]}` |
| 3 | `"tan"` | `"ant"` | `{"aet": ["eat", "tea"], "ant": ["tan"]}` |
| 4 | `"ate"` | `"aet"` | `{"aet": ["eat", "tea", "ate"], "ant": ["tan"]}` |
| 5 | `"nat"` | `"ant"` | `{"aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"]}` |
| 6 | `"bat"` | `"abt"` | `{"aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"], "abt": ["bat"]}` |
