# Balanced Binary Tree — проверка сбалансированности бинарного дерева

## Описание алгоритма

1. Если текущий узел отсутствует (`None`), возвращаем высоту `0`
2. Рекурсивно вычисляем высоту левого поддерева
3. Если левое поддерево несбалансировано (высота равна `-1`), сразу возвращаем `-1`
4. Аналогично вычисляем высоту правого поддерева и проверяем его баланс
5. Сравниваем высоты поддеревьев. Если их разница больше `1`, возвращаем `-1`
6. Если поддерево сбалансировано, возвращаем его высоту: `1 + max(left_height, right_height)`
7. После завершения проверки возвращаем `True`, если результат не равен `-1`, иначе `False`

## Оценка сложности

- \(n\) — количество узлов дерева.
- \(h\) — высота дерева.

**По времени: \(O(n)\).**

Каждый узел посещается не более одного раза. Высота каждого поддерева вычисляется при рекурсивном обходе, поэтому общее время работы пропорционально количеству узлов.

**По памяти: \(O(h)\).**

Память используется для стека рекурсивных вызовов. Максимальная глубина рекурсии равна высоте дерева.

- Для сбалансированного дерева высота обычно составляет \(O(\log n)\)
- Для вырожденного дерева высота может достигать \(O(n)\)

Т.е. временная сложность алгоритма — \(O(n)\), а доп память — \(O(h)\)

## Очень короткое описание

Проверяем отличаются ли высоты левого и правого поддеревьев каждого узла не более чем на `1`.

Для этого рекурсивно вычисляем высоты поддеревьев снизу вверх. Если обнаруживается несбалансированное поддерево, функция возвращает `-1` — специальный сигнал об ошибке
