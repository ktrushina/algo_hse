# Balanced Binary Tree — проверка сбалансированности бинарного дерева

## Условие задачи

Определить, является ли бинарное дерево сбалансированным по высоте.

Дерево сбалансировано, если для **каждого узла** высоты его левого и правого поддеревьев отличаются не более чем на 1. Функция `is_balanced(root)` возвращает `True`, если дерево сбалансировано, и `False` в противном случае.

## Условия на входе

- `root` — корень бинарного дерева или `None`, если дерево пустое.
- Каждый узел содержит ссылки `left` и `right` на дочерние узлы либо `None`.
- Предполагается, что вход представляет собой корректное бинарное дерево без циклов.
- Значения узлов не влияют на результат: проверяется только структура дерева, а не свойства бинарного дерева поиска (BST).
- Пустое дерево считается сбалансированным.
- Реализация использует рекурсию, поэтому на очень глубоком дереве может возникнуть ограничение глубины рекурсии Python.

## Идея алгоритма

Высоту каждого поддерева вычисляем рекурсивно, снизу вверх. Вспомогательная функция `height(node)` возвращает:

- `0`, если узел отсутствует (`None`);
- высоту поддерева, если оно сбалансировано;
- `-1`, если в поддереве найден дисбаланс. Значение `-1` используется как специальный сигнал, а не как реальная высота.

Алгоритм для каждого узла:

1. Если узел отсутствует, возвращаем высоту `0`.
2. Вычисляем высоту левого поддерева.
3. Если результат равен `-1`, сразу возвращаем `-1`: левое поддерево уже несбалансировано.
4. Аналогично вычисляем высоту правого поддерева и проверяем результат.
5. Если разница высот больше `1`, возвращаем `-1`.
6. Иначе возвращаем высоту текущего поддерева: `1 + max(left_height, right_height)`.
7. Внешняя функция `is_balanced(root)` возвращает `True`, если итоговый результат не равен `-1`, иначе `False`.

Такой подход позволяет за один обход вычислить высоты поддеревьев и проверить баланс, не пересчитывая высоту каждого поддерева многократно.

## Визуализация работы алгоритма

Рассмотрим дерево, в котором высоты левого и правого поддеревьев корня одинаковы, но внутри левого поддерева есть дисбаланс:

```text
          10
         /  \
        5    20
       /    /  \
      3    15   25
     /     /
    1     12
```

### Пошаговое выполнение

Обход идёт снизу вверх. Для каждого узла `height()` сначала получает результаты для дочерних поддеревьев, а затем либо возвращает высоту, либо сигнал `-1`.

| Шаг | Текущий узел | Высота слева | Высота справа | Действие / результат |
|---:|---:|---:|---:|---|
| 1 | `1` | `0` | `0` | Разница `0`; возвращаем высоту `1` |
| 2 | `3` | `1` | `0` | Разница `1`; возвращаем высоту `2` |
| 3 | `5` | `2` | `0` | Разница `2 > 1`; возвращаем `-1` |
| 4 | `10` | `-1` | Не вычисляется | Левое поддерево несбалансировано; возвращаем `-1` |
| 5 | Внешняя функция | — | — | `height(root) != -1` даёт `False` |

**Что важно:** алгоритм не вычисляет высоту правого поддерева узла `10`, потому что рекурсивный вызов для левого поддерева уже вернул `-1`. Это демонстрирует досрочное прекращение проверки после обнаружения дисбаланса.

### Схема логики алгоритма

```text
height(node)
    |
    v
Узел отсутствует?
    | Да                  | Нет
    v                     v
Вернуть 0           Вычислить высоту слева
                           |
                           v
                    Результат == -1?
                      | Да       | Нет
                      v          v
                 Вернуть -1   Вычислить высоту справа
                                  |
                                  v
                           Результат == -1?
                             | Да       | Нет
                             v          v
                        Вернуть -1   Разница высот > 1?
                                        | Да       | Нет
                                        v          v
                                   Вернуть -1   Вернуть
                                                1 + max(left, right)

После вызова height(root):
    - результат != -1  -> True
    - результат == -1  -> False
```

## Оценка сложности

Обозначения:
- `n` — количество узлов дерева;
- `h` — высота дерева.

**Временная сложность: `O(n)`.** Каждый узел посещается не более одного раза. Высоты поддеревьев вычисляются в рамках того же рекурсивного обхода.

**Дополнительная память: `O(h)`.** Она используется стеком рекурсивных вызовов. Для сбалансированного дерева высота обычно составляет `O(log n)`, а для вырожденного дерева может достигать `O(n)`.


## Очень короткое описание

Проверяем отличаются ли высоты левого и правого поддеревьев каждого узла не более чем на `1`.

Для этого рекурсивно вычисляем высоты поддеревьев снизу вверх. Если обнаруживается несбалансированное поддерево, функция возвращает `-1` — специальный сигнал об ошибке
