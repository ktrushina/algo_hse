# Tracer — декоратор для отслеживания рекурсии

## Задание

Реализовать декоратор, который показывает стек вызовов рекурсивной функции.

При каждом вызове декоратор должен выводить:
- Вход в функцию с её аргументами.
- Отступ, соответствующий текущей глубине рекурсии.
- Возврат из функции с полученным результатом.

## Описание 

**Идея:** декоратор оборачивает рекурсивную функцию и отслеживает глубину её вызовов с помощью счётчика

Алгоритм работает следующим образом:

1. Создаём список `depth = [0]`, в котором храним текущую глубину рекурсии.
2. При входе в функцию выводим её имя и аргументы с отступом, соответствующим глубине.
3. Увеличиваем глубину на 1 перед выполнением функции.
4. Вызываем исходную функцию и получаем результат.
5. Выводим результат с тем же отступом, что и при входе.
6. Уменьшаем глубину на 1 при завершении вызова.

Конструкция `try/finally` гарантирует восстановление счётчика глубины даже при возникновении ошибки.

## Пример использования

Рассмотрим рекурсивную функцию вычисления факториала.

```python
# Пример рекурсивной функции с декоратором
@tracer
def factorial(n):
    # Базовый случай: останавливаем рекурсию
    if n <= 1:
        return 1

    # Рекурсивно вычисляем факториал
    return n * factorial(n - 1)


factorial(4)
```

**Результат выполнения:**

```text
→ factorial(4,)
  → factorial(3,)
    → factorial(2,)
      → factorial(1,)
      ← factorial = 1
    ← factorial = 2
  ← factorial = 6
← factorial = 24
```

## Визуализация 

Рассмотрим вычисление `factorial(4)`.

**Этап 1. Вход в рекурсию**

Каждый следующий вызов увеличивает глубину рекурсии на 1.

```text
factorial(4)                 depth = 0
    |
    └── factorial(3)         depth = 1
            |
            └── factorial(2) depth = 2
                    |
                    └── factorial(1) depth = 3
```

**Этап 2. Возврат из рекурсии**

После достижения базового случая результаты возвращаются в обратном порядке.

```text
factorial(1) = 1
      ↓
factorial(2) = 2 * 1 = 2
      ↓
factorial(3) = 3 * 2 = 6
      ↓
factorial(4) = 4 * 6 = 24
```

**Вывод:** при углублении рекурсии отступ увеличивается, а при возврате уменьшается. Благодаря этому можно визуально проследить порядок вызовов и возвращаемые результаты.

## Оценка сложности

Обозначения:
- `n` — количество вызовов функции
- `h` — максимальную глубину рекурсии

**По времени: O(n · h)**

Декоратор выполняет дополнительные действия при каждом вызове функции: формирует отступ и выводит информацию.

Создание отступа занимает O(h) в худшем случае. Поэтому для `n` вызовов верхняя оценка временной сложности декоратора составляет O(n · h).

**По памяти: O(h)**

Для каждого вложенного вызова создаётся отдельный стековый кадр функции `wrapper`. Максимальное количество одновременно активных вызовов определяется глубиной рекурсии `h`.

Сам список `depth` занимает O(1) памяти.

Оценки относятся к дополнительным расходам декоратора без учёта вычислений исходной функции, размера аргументов и выводимых значений.



**Итог:** декоратор `tracer` позволяет отслеживать рекурсивные вызовы, отображая глубину вложенности, аргументы и результаты. При этом он сохраняет возвращаемое значение исходной функции и не требует дополнительных библиотек.
