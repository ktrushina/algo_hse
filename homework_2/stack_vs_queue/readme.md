# Stack vs Queue

## Объяснение решения

- **стек (stack)** — работает по принципу **LIFO** (Last In, First Out): последний добавленный элемент извлекается первым
- **очередь (queue)** — работает по принципу **FIFO** (First In, First Out): первый добавленный элемент извлекается первым.

Реализация с помощью **связного списка**.

Связный список состоит из узлов (`Node`). Каждый узел хранит:

- `data` — значение элемента;
- `next` — ссылку на следующий узел.

### Стек

Для стека используется указатель `top`, который указывает на вершину стека.

При добавлении элемента (`push`) создаётся новый узел. Его `next` начинает указывать на текущий `top`, после чего `top` переносится на новый узел:

```text
До добавления:

top
 ↓
[20] → [10] → None

Добавляем 30:

top
 ↓
[30] → [20] → [10] → None
```

При удалении (`pop`) значение из `top` возвращается, а `top` переносится на следующий узел:

```text
До pop():

top
 ↓
[30] → [20] → [10] → None

После pop():

top
 ↓
[20] → [10] → None

Возвращается: 30
```

### Очередь

Для очереди используются два указателя:

- `first` — начало очереди, откуда удаляются элементы
- `last` — конец очереди, куда добавляются элементы.

При добавлении (`enqueue`) новый узел добавляется после `last`, а `last` переносится на новый узел:

```text
first                    last
 ↓                         ↓
[10] → [20] → [30] → None
```

При удалении (`dequeue`) удаляется узел, на который указывает `front`, а `front` переносится на следующий узел:

```text
До dequeue():

first                    last
 ↓                         ↓
[10] → [20] → [30] → None

После dequeue():

       first              last
         ↓                 ↓
[20] → [30] → None

Возвращается: 10
```

## Оценка сложности

### Стек

| Операция | Время | Память |
|---|---:|---:|
| `push()` | O(1) | O(1) |
| `pop()` | O(1) | O(1) |
| `peek()` | O(1) | O(1) |
| `is_empty()` | O(1) | O(1) |

`push()` и `pop()` работают за O(1), потому что для добавления и удаления достаточно изменить указатель `top`. Перебирать весь список не требуется.

Общая память для самого стека из `n` элементов составляет **O(n)**, так как для каждого элемента создаётся отдельный узел.

### Очередь

| Операция | Время | Память |
|---|---:|---:|
| `enqueue()` | O(1) | O(1) |
| `dequeue()` | O(1) | O(1) |
| `peek()` | O(1) | O(1) |
| `is_empty()` | O(1) | O(1) |

В очереди используются два указателя — `first` и `last`. Поэтому новый элемент можно добавить в конец списка, а удалить из начала. Перебирать остальные элементы не требуется.

Общая память для очереди из `n` элементов составляет **O(n)**, так как для каждого элемента создаётся отдельный узел.

## Визуализация Stack
```
LIFO

    push, pop ↓

      ┌──────┐
top → │  30  │
      ├──────┤
      │  20  │
      ├──────┤
      │  10  │
      └───┬──┘
          ↓
        None
```
## Визуализация Queue
```
FIFO 

  first          last
     ↓             ↓
   ┌────┐  →  ┌────┐  →  ┌────┐
   │ 10 │     │ 20 │     │ 30 │
   └────┘     └────┘     └────┘

     ↑                    ↑
  dequeue              enqueue(потом указатель last перейдет сюда)

  ```
