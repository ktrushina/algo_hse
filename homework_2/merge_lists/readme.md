# Merge Lists

## Объяснение решения

Дано 2 отсортированных односвязных списка `list1` и `list2`.

Нужно объединить их в один отсортированный список.

Здесь реализованы два способа:

1. с использованием **фиктивного элемента (`dummy`)**;
2. **без фиктивного элемента**.

В обоих случаях используются узлы исходных списков. Новые узлы для каждого элемента не создаются, изменяются ссылки `next`.

## Решение с фиктивным элементом

Для упрощения работы создаётся дополнительный узел `dummy`.

Он не является частью результата. Его задача — хранить начало создаваемого списка и избежать отдельной обработки первого элемента.

Используется указатель `current`, который показывает на последний добавленный узел.

  
```text
dummy
  ↓
[0] → None
  ↑
current
```

Рассмотрим:

```text
list1: 1 → 2 → 4
list2: 1 → 3 → 4
```

Сравниваем первые элементы:

```text
1 ≤ 1

dummy
  ↓
[0] → [1]
         ↑
      current
```

Затем сравниваем `2` и `1`:

```text
1 < 2

dummy
  ↓
[0] → [1] → [1]
              ↑
           current
```

Продолжаем сравнение:

```text
list1:       2 → 4
list2:       3 → 4

2 < 3 → берём 2

result:
[1] → [1] → [2]
              ↑
           current
```

Далее:

```text
3 < 4 → берём 3

[1] → [1] → [2] → [3]
                     ↑
                  current
```

Затем добавляются оставшиеся элементы:

```text
[1] → [1] → [2] → [3] → [4] → [4]
```

Финальный результат:

```text
1 → 1 → 2 → 3 → 4 → 4
```

После этого возвращается:

```python
dummy.next
```

То есть первый настоящий элемент списка, а сам `dummy` в результат не входит.

## Решение без фиктивного элемента

Во втором варианте `dummy` не используется.

Сначала необходимо определить, какой из первых элементов списков станет головой результата.

Например:

```text
list1: 1 → 2 → 4
list2: 1 → 3 → 4
```

Первые элементы равны, поэтому можно взять первый элемент `list1`:

```text
head
 ↓
[1] → [2] → [4]
```

После выбора головы указатель `current` устанавливается на неё:

```text
head
 ↓
[1] → [2] → [4]
 ↑
current
```

Затем сравниваются оставшиеся элементы обоих списков.

```text
list1: 2 → 4
list2: 1 → 3 → 4
```

Берём `1` из `list2`:

```text
head
 ↓
[1] → [1]
         ↑
      current
```

Дальше:

```text
list1: 2 → 4
list2: 3 → 4

2 < 3 → берём 2
```

Получаем:

```text
head
 ↓
[1] → [1] → [2]
              ↑
           current
```

Продолжаем до конца:

```text
head
 ↓
[1] → [1] → [2] → [3] → [4] → [4]
```

Возвращается `head`.

---

## Обработка оставшихся элементов

Когда один из списков заканчивается, второй список уже остаётся отсортированным.

Например:

```text
list1: 1 → 2 → 4
list2: 3
```

После нескольких сравнений может получиться:

```text
result: 1 → 2 → 3
```

В `list1` остался:

```text
4
```

Так как `4` уже находится в правильном месте, можно просто присоединить оставшуюся часть:

```text
result: 1 → 2 → 3 → 4
```

Поэтому в конце алгоритма выполняется:

```python
if list1 is not None:
    current.next = list1
else:
    current.next = list2
```

## Оценка сложности

Для обоих способов используется одинаковый принцип сравнения элементов.

| Операция | Время | Доп. память |
|---|---:|---:|
| Сравнение двух элементов | O(1) | O(1) |
| Добавление узла в результат | O(1) | O(1) |
| Слияние двух списков | O(n + m) | O(1) |

### По времени O(n + m)

Каждый узел каждого списка (n элементов в первом списке, m во втором) обрабатывается не более одного раза.

### По памяти: O(1)

Новые узлы для элементов не создаются.

Мы только меняем ссылки `next` уже существующих узлов

```text
list1 ──┐
        ├──→ result
list2 ──┘
```

В версии с `dummy` создаётся один дополнительный узел. Это всё еще `O(1)` доп памяти.

## Визуализация

```text
                 С dummy                    Без dummy
                    │                           │
                    ▼                           ▼
             создаём [0]                 выбираем head
                    │                           │
                    ▼                           ▼
             начинаем с dummy            начинаем с head
                    │                           │
                    └──────────┬────────────────┘
                               ▼
                    Сравниваем узлы
                               │
                               ▼
                    Берём меньший узел
                               │
                               ▼
                    Меняем ссылки next
                               │
                               ▼
                         Готовый список
```

- с `dummy` — сразу можем присоединять первый узел;
- без `dummy` — сначала отдельно выбираем `head`.

**С `dummy`** проще реализовать добавление первого элемента, потому что `current` с самого начала указывает на существующий узел.

**Без `dummy`** нужно отдельно определить `head`, сравнив первые элементы двух списков.

(При этом сложность обоих решений одинаковая)
