# algo_hse
Алгоритмы на Python (курс Avito x HSE)

## Запуск тестов

### Установить библиотеки

```bash
pip install -r requirements.txt
```

### Запуск всех тестов

Из корневой папки репозитория выполнить:

```bash
pytest
```

После запуска `pytest` автоматически найдёт **все** тесты в репозитории и выполнит их

### Запуск тестов для какого-то отдельного задания

Например, для `prime`:

```bash
pytest homework_1/prime/
```

Для `sum`:

```bash
pytest homework_1/sum/
```

### Итого

Если все тесты прошли успешно, pytest покажет:

```text
... passed
```

Если какой-либо тест не пройден, pytest покажет информацию о том, какой тест завершился с ошибкой
